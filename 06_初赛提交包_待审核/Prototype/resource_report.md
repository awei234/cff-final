## 4. 论文生成过程：模型、Token 与耗时

统计对象为论文工程的完整生成会话。会话记录中同一 API 响应会重复写入 2–4 条，因此调用按 `message.id` 去重、工具按 `tool_use.id` 去重；未去重会将计数虚高约 2.3 倍。

| 指标 | 实测值 |
|---|---:|
| 模型 API 响应次数（去重） | 304 次 |
| 原始 assistant 记录数（未去重） | 约 700 条 |
| 输入 Token（未命中缓存） | 398,402 |
| 输入 Token（缓存读取） | 29,147,904 |
| 输出 Token | 317,068 |
| Token 合计 | 29,863,374 |
| 活跃模型调用时间 | 69 分钟（约 1.2 小时） |
| 会话自然跨度 | 41.5 小时（含人工审阅与空闲等待） |

缓存读取量按每次请求重读完整上下文累计，是真实计费口径下的输入量，但不等同于 2,915 万个不重复 Token。此会话仍可能续写，以上为截止时刻快照。

### 论文生成过程：工具、磁盘与硬件

- 去重后的工具调用为 311 次：Bash 177、Edit 65、Read 46、Write 17、WebFetch 2、WebSearch 1、Skill/Agent/AskUserQuestion 各 1；
- 论文工程当时为 73 个文件、约 12.8 MiB；英文投稿 PDF 为 15 页、约 1.03 MiB；
- 本机为 Intel Core i5-13420H、15.7 GB 内存、Windows 11；无独立 NVIDIA GPU，本地不做模型推理，显存使用为 0；
- 远端模型 API 请求为 304 次，公网检索为 3 次；出网字节未记录，不作估算。

上述论文生产数据只说明成稿过程的资源消耗；它不替代第 2–3 节中提交 Agent 的运行证据、成本记录或可复现性结论。
