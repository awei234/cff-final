## 3. 审核命令

```powershell
python verify_submission.py --stage review
```

预期：`valid=true`，同时列出论文和 Token 两个待补项。

补齐后：

```powershell
python verify_submission.py --stage final
```

最终阶段必须为 `valid=true`，并人工核验英文 ICLR 排版及 Token 与论文的对应关系后，才能压缩。脚本本身不验证评审服务 Token 有效性。

## 4. 代码环境

- JiuwenSwarm 使用 Python >=3.11,<3.14（推荐 3.11 或 3.12）；独立 UCR 核心可用 Python 3.10+；
- 测试使用 pytest 8+；
- JiuwenSwarm 依赖见 `code/03_技术实现/jiuwenswarm/pyproject.toml` 和 `uv.lock`；
- 前端依赖见对应 `package.json` 和锁文件；
- 不提交 `.venv` 或 `node_modules`。

## 6. 结论边界

- UCR 是过程证据指标，不是领域准确率；
- JIT v2 是确定性 fixture，不产生模型费用；
- seed 43/44 的新增来源未获正式引用批准；
- 只有授权运行中的允许来源和 Claim 可以进入论文。

## 7. 压缩前检查

1. 补入正式英文 ICLR 论文。

4. 重新生成 `CHECKSUMS.sha256`。
5. 运行 final 校验。
6. 人工检查后再生成 `Prototype.zip`；本轮不压缩。
