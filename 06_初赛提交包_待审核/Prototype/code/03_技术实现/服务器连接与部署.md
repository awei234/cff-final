## 3. 便捷连接脚本

**服务器侧**（已建）：`~/bin/ccfssh.sh`

```bash
#!/bin/bash
# CCF 比赛服务器便捷连接脚本（SSH 免密）
# 用法: ccfssh.sh           # 交互式登录
#       ccfssh.sh '命令'    # 执行单条命令
ssh -o BatchMode=yes -o ConnectTimeout=10 vergil@10.182.68.242 "$@"
```

**本地工作区副本**（本目录 `scripts/ccfssh.sh`，用法同上）。

### 部署中踩过的坑（备查）
1. venv_test 的 Python 缺 ensurepip → 用 `--without-pip` + get-pip.py 补装
2. **pip 默认走海外 pypi.org 极慢（328 B/s）** → 配阿里云镜像（1.3 MB/s，快 4000 倍）到 `~/.config/pip/pip.conf`
3. `.env` 必须放 `~/.jiuwenswarm/config/.env`（框架自动加载位置），不是 `~/.jiuwenswarm/.env`
4. `pkill -f jiuwenswarm` 会误杀 ssh 会话 → 用 `ss -tlnp | grep :19001` 定位 PID 精确停止
5. 停服务：`ss -tlnp | grep 19001` 找 PID → kill；再启动前确认无残留
