# 提交文档索引

本目录存放评审所需的技术说明，不存放运行态配置或密钥。

- `architecture.md`：系统架构、数据流与安全边界；
- `module_call.md`：JiuwenSwarm / openJiuwen 模块调用关系；
- `innovation.md`：Claim–Evidence、UCR 与受约束 JIT Harness 的创新说明；
- `reports/`：阶段报告与交接材料。该目录内标有历史状态的文件仅作追溯，当前状态以包根 `提交说明.md`、`审核清单.md` 和 `submission_manifest.json` 为准。

提交入口与最终校验命令见包根 `提交说明.md`。
