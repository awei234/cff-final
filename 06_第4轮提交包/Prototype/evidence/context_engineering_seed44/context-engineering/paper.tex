\section{研究问题与计划}
\textbf{问题：}程序级证据护栏能否提高 Agent 执行报告的证据一致性？\\
\textbf{假设：}full-\allowbreak{}rail 应比无护栏或仅提示词减少无证据完成声明。
\begin{itemize}
\item 三臂均 status=completed 且 return\_\allowbreak{}code=0。
\item UCR 可计算：no-\allowbreak{}rail=5 / 9，prompt-\allowbreak{}only=0 / 4，full-\allowbreak{}rail=0 / 4。
\item full-\allowbreak{}rail 的 UCR 不高于 no-\allowbreak{}rail 与 prompt-\allowbreak{}only。
\item full-\allowbreak{}rail 的 rail.accepted=true 且 attempts=1。
\item 所有结论均绑定 claim\_\allowbreak{}id 与 evidence / source ref。
\end{itemize}
\section{方法}
按 arm 运行 no-\allowbreak{}rail、prompt-\allowbreak{}only、full-\allowbreak{}rail 三臂，记录 UCR、task\_\allowbreak{}success\_\allowbreak{}rate、rail 状态与 decisions[].status。按 operation\_\allowbreak{}id 对齐三臂决策，比较 supported 与 unexecuted 计数。UCR 仅作为 process\_\allowbreak{}evidence\_\allowbreak{}only，不推断任务质量或真实完成度。

\section{结论}
