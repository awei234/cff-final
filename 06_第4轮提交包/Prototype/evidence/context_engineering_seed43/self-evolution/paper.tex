\section{研究问题与计划}
\textbf{问题：}带证据的反思循环能否避免把未执行任务写成已完成？\\
\textbf{假设：}证据检查可能改善审计表达，但当前基准不证明真实自我进化。
\begin{itemize}
\item 所有实验臂完成且返回码为0。
\item UCR按unexecuted / 分母正确计算并标注为measured。
\item 决策状态与理由可追溯到操作级证据。
\item 结论不超出当前基准，不声称证明真实自我进化。
\item 引用受citation\_\allowbreak{}allowed=false限制，不进行正式引用。
\end{itemize}
\section{方法}
比较 no-\allowbreak{}rail、prompt-\allowbreak{}only、full-\allowbreak{}rail 三个实验臂，对每个决策操作记录状态与理由，区分 supported 与 unexecuted，并按 unexecuted / 分母计算 UCR，同时记录 rail.enabled、attempts、accepted。
