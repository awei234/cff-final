# 完整源码范围

本目录来自冻结的 `03_技术实现` 源码树，包含 competition runner、UCR benchmark、custom rails、Research Pipeline Skill、JiuwenSwarm、测试、配置和必要资源。

公开包只排除运行结果、缓存、依赖目录、本地密钥文件，以及两张含邮箱的文档截图。邮箱、API Key 样例和机器绝对路径在公开副本中替换为占位符；原始证据没有被修改。具体数量见包根 `submission_manifest.json` 的 `source_inventory`。

提交包级架构、模块调用关系及复现入口分别见 `../docs/architecture.md`、`../docs/module_call.md` 和 `../提交说明.md`；实验产物不在本目录，统一见 `../evidence/`。
