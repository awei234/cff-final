\section{研究问题与计划}
\textbf{问题：}程序级证据护栏能否提高 Agent 执行报告的证据一致性？\\
\textbf{假设：}full-\allowbreak{}rail 应比无护栏或仅提示词减少无证据完成声明。
\begin{itemize}
\item 三个 arm 均 status=completed 且 return\_\allowbreak{}code=0。
\item UCR 在 full-\allowbreak{}rail 中低于 no-\allowbreak{}rail 与 prompt-\allowbreak{}only。
\item full-\allowbreak{}rail 的 rail.enabled=true 且 rail.accepted=true。
\item 所有 supported 决策均有 matching\_\allowbreak{}successful\_\allowbreak{}evidence 作为 reason。
\end{itemize}
\section{方法}
在相同任务集上运行 no-\allowbreak{}rail、prompt-\allowbreak{}only、full-\allowbreak{}rail 三个 arm，记录 return\_\allowbreak{}code、task\_\allowbreak{}success\_\allowbreak{}rate、rail 状态与每个 operation\_\allowbreak{}id 的 decision.status / reason。UCR 分母为全部完成声明，分子为无匹配证据的完成声明。实验结论仅引用本次记录；三条背景来源已单独批准正式引用。
