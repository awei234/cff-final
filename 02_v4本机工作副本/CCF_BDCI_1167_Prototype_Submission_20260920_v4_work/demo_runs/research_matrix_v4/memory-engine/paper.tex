\section{研究问题与计划}
\textbf{问题：}结构化记忆记录是否有助于 Agent 保持审计上下文一致？\\
\textbf{假设：}结构化记录可能改善流程可追溯性，但当前基准不证明领域效果。
\begin{itemize}
\item 三组运行均 completed 且 return\_\allowbreak{}code=0。
\item UCR 按 supported / (supported+unexecuted) 计算并标注 status=measured。
\item task\_\allowbreak{}success\_\allowbreak{}rate 记录为 1.0。
\item 不将 citation\_\allowbreak{}allowed=false 的来源作为正式引用。
\item 结论明确区分过程可追溯性与领域效果。
\end{itemize}
