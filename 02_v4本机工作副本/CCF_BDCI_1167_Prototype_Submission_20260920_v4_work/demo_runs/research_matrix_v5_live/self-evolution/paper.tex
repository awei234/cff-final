\section{研究问题与计划}
\textbf{问题：}带证据的反思循环能否避免把未执行任务写成已完成？\\
\textbf{假设：}证据检查可能改善审计表达，但当前基准不证明真实自我进化。
\begin{itemize}
\item full-\allowbreak{}rail的UCR低于no-\allowbreak{}rail的UCR。
\item full-\allowbreak{}rail的未执行操作不被标记为supported。
\item 任务成功率不因证据检查而显著下降。
\item 所有结论可追溯到具体实验臂的决策记录。
\end{itemize}
\section{方法}
在相同任务集上运行三个实验臂：no-\allowbreak{}rail（无rail）、prompt-\allowbreak{}only（仅提示）、full-\allowbreak{}rail（启用rail）。对每个操作记录决策状态（supported / unexecuted / indeterminate）及理由，计算UCR=未执行但被写成已完成的比率。citation\_\allowbreak{}allowed=false的材料不作为正式引用。
\subsection{实验设置}
no-\allowbreak{}rail：rail.enabled=false，attempts=0，accepted=true，9个操作中4个supported、5个unexecuted。prompt-\allowbreak{}only：rail.enabled=false，attempts=0，accepted=true，4个操作均supported。full-\allowbreak{}rail：rail.enabled=true，attempts=1，accepted=true，4个操作均supported。三臂return\_\allowbreak{}code均为0，任务成功率均为1.0。CFR与NFR在UCR场景中未测量。
