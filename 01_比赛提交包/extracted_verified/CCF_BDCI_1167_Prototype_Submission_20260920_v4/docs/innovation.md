# 创新与贡献

工程贡献是把“完成声明必须有成功工具事件”实现为 JiuwenSwarm 生命周期中的 Rail，并保存拒绝、重写和最终选择证据。补丁基于项目锁定版本，提供独立应用检查；没有虚构上游 PR 或合并状态。

实验贡献是冻结 no-rail、prompt-only、full-rail 三组协议，以独立评分器计算 UCR。原始 GLM/Qwen 实验得到 pooled UCR 24/106、3/82、0/80。独立 DeepSeek 复现得到 21/61、5/74、0/53；full-rail 的 5 个任务因三次尝试后仍未被 Rail 接受而保留为 partial。

审核贡献是对 DeepSeek 的 237 条声明进行固定分层抽样，获得 50 条最终真人标签。自动评分器与最终人工标签一致 38/50，交叉模型一致 44/50。这些是抽样一致率，不代表总体准确率。审核人身份和独立完成确认尚未记录，因此不宣称完整人工校准已经验收通过。
