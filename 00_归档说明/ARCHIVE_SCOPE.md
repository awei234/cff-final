# 归档范围说明

## 包含

- v4 比赛提交包及其可验证解压副本；
- v4 本机工作副本；
- 服务器 JiuwenSwarm 源码快照；
- 服务器 custom_rails 源码快照；
- 服务器 v4 实验结果、mock 记录和历史 retry 记录；
- 清理规则、文件清单、SHA-256 校验和及敏感信息扫描报告。

## 不包含

- 服务器 Git 历史 `.git`；
- `.pyc`、`__pycache__`、`.pytest_cache`；
- 模型缓存和临时下载文件；
- 运行日志；
- API Key、SAR Token、Authorization Header；
- 用户私有审稿材料；
- 比赛网页提交凭证；
- 服务器原始目录本身的修改内容。

## 关于比赛提交

`01_比赛提交包` 是独立的比赛提交材料。`03_服务器源码快照` 和 `04_服务器v4实验工作区` 是开发归档，不应直接与比赛 ZIP 合并上传。
